# ADMIN-CONSOLE-00003 — UI per invocare script di diagnostica

**Stato:** todo

**Blocca:** ADMIN-CONSOLE-00001

## Task

UI nella console admin per invocare gli script di diagnostica esistenti (es.
`diagnose-full-context.ts`) senza dover usare la riga di comando, con output leggibile in
pagina.

## DoD

Un admin può selezionare uno script di diagnostica esistente, fornire i parametri necessari
(es. gioco, domanda) dalla UI, ed ottenere l'output della diagnosi renderizzato in pagina.
